# Änderungen / Changes

## 0.7.0

**English**

- **New repository:** the integration and dashboard card now live in their own repository `Thomas1607Haja/rezeptplaner-ha` with their own releases, so HACS shows the right version and offers updates. Moving from the old repository: see the README. The domain stays `rezeptplaner`; your setup is kept.
- **Five languages:** setup, entities, calendar entries, sensor and card in English, German, French, Spanish and Italian. The integration uses the Home Assistant system language, the card the language of the logged-in user; English is the fallback.
- Own icon for the integration (Home Assistant 2026.3 or newer).

**Deutsch**

- **Neues Repository:** Integration und Dashboard-Karte liegen jetzt in einem eigenen Repository `Thomas1607Haja/rezeptplaner-ha` mit eigenen Releases – HACS zeigt damit die richtige Version und meldet Updates. Umstieg vom alten Repository: siehe README. Die Domain bleibt `rezeptplaner`, die Einrichtung bleibt erhalten.
- **Fünf Sprachen:** Einrichtung, Entitäten, Kalendertermine, Sensor und Karte auf Deutsch, Englisch, Französisch, Spanisch und Italienisch. Die Integration nutzt die Systemsprache von Home Assistant, die Karte die Sprache des angemeldeten Nutzers; Rückfall ist Englisch.
- Eigenes Icon für die Integration (ab Home Assistant 2026.3).
